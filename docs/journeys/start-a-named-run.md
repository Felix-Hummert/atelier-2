# Start a named run

The operator opens Studio at `/atelier`. The heading is **Studio**.

If the workshop is empty, the empty area names the one next act: **Start a
run**. If runs already exist, **Start** sits in the header. Both go to
`/atelier/new`. The trail reads Studio → This workshop → New run.

The new-run heading is **Choose a workflow**. Under **Saved workflow** the
operator picks a published name. A V3 document that declares orders then shows
**Material** / **Orders**: one textarea per order, labelled **Material**. A
document that declares agent roles shows **Agent setup** / **Bindings**: each
role has an **Agent** select of published configurations, labelled
`provider · model · Subscription` or `provider · model · API key`.

**Start** posts the exact start. The cockpit opens
`/atelier/runs/{public_run_reference}`. A V3 run draws the same published
graph it was started from: **Following live**, the rail, a click into a node.

That walk is landed: the picker, the named-agent select, the material fields,
start, and the V3 graph view. This page does not describe a conductor, a
library, or a canvas that composes a new graph.
